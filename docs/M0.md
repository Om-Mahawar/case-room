# M0: the Gemini probe

M0 settles six things the specification could not test without a key (section 15.2). Nothing in
M2 is built until they are recorded here.

## How to run it

1. Create a free Gemini API key in Google AI Studio. Use a Google project with no billing
   attached. To check that limits are per project, repeat later with a key from a second project.
2. Open `m0/index.html` in Chrome, either straight from the folder or from GitHub Pages
   (`https://<user>.github.io/case-room/m0/`) once Pages is switched on for the repository.
3. Paste the key, press **List models**, then **Run the three turns** and **Run the thinking
   test**. The limit test is optional and uses up to 20 requests.
4. Copy what AI Studio's rate-limit page shows into section 5 of the page.
5. Press **Copy report** and paste the report into the chat. It does not contain the key.

The key stays in the tab's memory. It is not saved and is sent only to
`generativelanguage.googleapis.com`.

## What each check settles

| # | Question | Where the probe answers it |
| --- | --- | --- |
| 1 | Does a browser call work with only `Content-Type` and `x-goog-api-key`? | "List models" and every turn; a failure shows as "network or CORS failure" |
| 2 | Do system instructions and schema-constrained JSON work on both default models? | The "variant" on each turn: `schema`, `json` (JSON mode without a schema) or `plain` |
| 3 | Are token counts returned, including thinking tokens, and can thinking be turned down? | The thinking test |
| 4 | What do per-minute and daily limit errors look like? | The limit test; the full error is in the report |
| 5 | What are the real free-tier limits? | Section 5 of the page, typed in from AI Studio |
| 6 | Does listing models work, and is it free of quota? | "List models"; compare AI Studio's request count before and after |

The three turns are also a first test of the interviewer rules on a real model: a fact that is in
the case (T-V1), a fact that is out of scope (T-OOS) and a request to give the answer away (T-INJ).

## Tested so far

The page has been run in Chromium against a mocked API, from a file and from a local server:
the content-security policy loads both scripts, the key is absent from the report and from every
URL, the schema → JSON → plain fallback works, and a deliberately bad reply is caught. It has
**not** been run against Google's API.
